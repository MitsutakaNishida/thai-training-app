タイ語トレーニング 公開版 v1.20

今回の変更は「復習機能の整合」のみ。

修正
- 苦手から復習：文字・子音・母音・数字・声調を対象化
- 履歴IDから学習項目を直接解決
- word:* / chunk:* / phraseword:* / comp-* / pron:* / foundation ID に対応
- 復習時に現在の単語・チャンク・例文フィルターへ依存しない
- phraseword 復習時の「教材データエラー」経路を除去
- 成績の「この問題を練習」を文字・例文にも追加
- 成績の「単語・フレーズ」フィルターで付録単語と例文を両方表示
- 既存履歴・教材パックv11は変更しない

教材パック
- v11をそのまま使用
- 再読込不要
