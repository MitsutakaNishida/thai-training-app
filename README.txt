タイ語トレーニング 公開版 v1.23

変更内容
1. 子音を 全44 / 中子音9 / 高子音11 / 低子音24 で学習可能
2. 順番 / ランダムとクラス別学習を併用可能
3. 各子音に「中子音 / 高子音 / 低子音」を表示
4. 教科書字体 / Web字体を切替可能
5. 同じ文字を2字体で並べて比較可能
6. Web字体は代表的なループなし字体。実サイトではフォントごとに多少字形が異なる
7. 苦手復習から文字を開く場合、クラスフィルタに邪魔されず必ず対象文字を表示
8. v1.22の苦手判定・3連続正解卒業・カテゴリ横断復習を維持

字体
- 教科書字体: Noto Sans Thai Looped 優先、iOSでは Thonburi にフォールバック
- Web字体: Noto Sans Thai 優先、iOSでは Sukhumvit Set にフォールバック
- オンライン時はGoogle Fontsを利用。取得できない場合も端末フォントで表示

教材パックv11は変更なし・再読込不要
学習履歴localStorageキーも変更なし
