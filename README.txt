タイ語トレーニング 公開版 v1.25.1

主な修正
- トレーニングに「文字 → 発音」を追加。タイ文字から教材の発音記号・ローマ字を入力して答える
- 子音 / 母音 / 混合を切替可能。子音は中＋高 / 中 / 高 / 低 / 全部を選択可能
- 初期設定は現在の学習範囲に合わせ「子音・中＋高・弱点優先」
- 文字練習の正答率・ミス・連続正解と、文字→発音の成績を使った重み付き出題を追加
- 文字→発音の成績は sound:<既存ID> として別記録し、既存の文字練習成績/localStorageデータを変更しない
- ŋ→ng、ʉ→ue、ɛ→ae、ɔ→aw、ə→oe の簡易キーボード入力を許容
- 母音の読み上げ例を ก 系から อ を母音の台にする形へ変更（例：โอะ / โอ）。何を再生するか画面にも明示
- 文字→発音の誤答も苦手復習・成績画面に連携
- v1.24の3回正解後卒業、ミス後の苦手化、復習終了後ホーム復帰等の既存ロジックを維持

互換性
- 教材パック v11 は変更せず、そのまま使用できます。
- 学習履歴キー thai_training_records_v2 は変更していません。
- Service Worker キャッシュ: thai-training-public-v1-25
