タイ語トレーニング 公開版 v1.22

今回の変更：苦手判定と苦手復習UXの統一

【苦手の定義】
- 1回以上ミスしたことがある
- かつ、現在の連続正解が3回未満
- 3回連続正解で苦手卒業
- 卒業後に再び間違えると即座に苦手へ復帰
- 正解しかしていない問題は苦手復習には入らない

【統一】
- ホーム「要復習」
- 成績画面「苦手」
- ホーム「苦手から復習」
上記すべて同じ isWeakRecord() 判定を使用。

【苦手復習UX】
- 上部の「前の苦手問題 / 次の苦手問題」を削除
- 上部は「苦手復習 n / 全件」「問題カテゴリ」「間違えた問題だけを復習中」の表示のみ
- 苦手復習中は、通常学習用のカテゴリ・Lesson・順番/ランダム・前後移動などを非表示
- 各問題本来の回答操作で記録し、次の苦手問題へ進む
- 発音は「もう一度」「できた」のどちらも、苦手復習中は記録後に次の苦手問題へ進む
- 文字 / 単語 / チャンク / 例文 / タイ作文 / 発音のカテゴリ横断キューは維持

教材パックv11は変更なし。再読込不要。
