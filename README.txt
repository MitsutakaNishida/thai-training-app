タイ語トレーニング v1.0（GitHub公開用）

このZIPには市販教材の本文画像・付属音声・本文データを含みません。
GitHub Pagesにはこのフォルダの中身だけをアップロードしてください。

初回起動：
1. 「教材読込」を開く
2. new_express_private_pack_v1.zip を選ぶ
3. 画像・音声・LessonデータがIndexedDBへ保存される
4. 以後は教材パックを再選択しなくても利用可能

注意：
iPhoneのストレージ管理等でWebサイトデータが削除される可能性があるため、教材パックZIPはFilesアプリに保管してください。
学習履歴は localStorage の thai_training_records_v2 を継続利用します。
